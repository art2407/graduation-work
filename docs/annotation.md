# АННОТАЦИЯ

Выпускная квалификационная работа посвящена разработке веб-приложения для комплексного учёта и координации студенческих событий и мероприятий в образовательной организации.

Актуальность работы обусловлена отсутствием специализированных инструментов, объединяющих в единой среде функции публикации мероприятий, регистрации участников, учёта посещаемости и своевременного информирования — при широко распространённой практике использования разрозненных сторонних сервисов.

В работе проведён анализ предметной области и существующих аналогов (TimePad, 1С, «Статус»), на основе которого сформированы функциональные и нефункциональные требования к разрабатываемой системе. Выполнено проектирование реляционной модели данных PostgreSQL, включающей восемь сущностей, и трёхуровневой клиент-серверной архитектуры с паттерном Controller-Service-Repository.

Серверная часть реализована на платформе Node.js с применением фреймворка NestJS и ORM-инструмента Prisma. Аутентификация построена на механизме JWT с двумя токенами. Фоновая обработка уведомлений организована через очередь BullMQ на основе Redis. Клиентская часть реализована в виде SPA/PWA-приложения на основе React и Vite с применением библиотеки Material UI.

По результатам функционального тестирования (17 тест-кейсов) и проверки устойчивости (8 нештатных сценариев) все тесты пройдены успешно. Сравнительный анализ подтвердил, что разработанное решение обеспечивает функциональное покрытие, превосходящее аналоги по таким критериям, как push-уведомления об изменении расписания, QR-чек-ин участников и поддержка PWA.

Практическая значимость работы заключается в получении готового к развёртыванию программного продукта, снижающего организационные издержки проведения студенческих мероприятий и повышающего вовлечённость участников.
