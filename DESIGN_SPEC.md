### 1.3 Радиусы и тени

```
--radius-xs:  4px   — теги, чипы
--radius-sm:  8px   — кнопки, инпуты
--radius-md: 12px   — иконки, аватары
--radius-lg: 16px   — карточки
--radius-xl: 24px   — модалки, bottom sheets
--radius-full: 999px — pill-кнопки, бейджи

--shadow-card:   0 4px 12px rgba(30,27,75,.08)
--shadow-appbar: 0 2px 8px  rgba(30,27,75,.10)
--shadow-modal:  0 16px 40px rgba(30,27,75,.18)
--shadow-btn:    0 2px 6px  rgba(79,70,229,.30)
```

### 1.4 Отступы (spacing)

```
4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64px
```

```
xs: < 600px   — мобильный (390px)
```

| Primary Button | `Button` variant="contained" |
